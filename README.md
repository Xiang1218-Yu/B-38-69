# 🎮 游戏阵容助手

这是一个简单的游戏阵容查询工具。可以通过它快速找到游戏搭配，查看详细的英雄和装备需求，并且把喜欢的阵容收藏起来。

## ✨ 主要功能

- **浏览阵容**：滚动阵容列表，可以动态加载游戏阵容。
- **快速查找**：
  - **筛选**：支持按阵容强度（S级、A级等）进行筛选。
  - **搜索**：直接输入阵容名字或英雄名字，就能找到相关搭配。
- **详细信息**：点击卡片进入详情页，可以查看完整的阵容详情。
- **本地收藏**：点击心形图标即可收藏阵容。
- **多端适配**：无论是在大屏幕还是小屏幕上，界面都能自适应。

## 🛠️ 技术简介

项目使用了现代化的前端技术开发：

- **框架**: React + TypeScript + Vite
- **界面**: Material UI (MUI)
- **数据**: Redux Toolkit
- **路由**: React Router

## 🚀 快速启动

**1. 安装依赖 **

```bash
npm install
```

**2. 构建项目**

```bash
npm run build
```

**3. 启动项目**

```bash
npm run dev
```

**Docker 部署** (可选)

```bash
docker-compose up
```
